# Обратная связь по проектному семинару

[Открыть форму обратной связи](https://forms.yandex.ru/u/6ac504a2068ff07b7d5477dd/)

Расскажите, что понравилось в курсе, какие возникли проблемы и что стоит изменить или добавить.

В форме два поля:

- **Ваши замечания, предложения или идеи по курсу** — обязательное поле для отзыва.
- **ФИО — по желанию** — оставьте пустым, если хотите отправить отзыв анонимно.

Для заполнения формы аккаунт Яндекса не нужен.
